## 工廠運作

### 工廠 (factory)

工廠是這個 repo。它的產出是產品。

_避免_：產線（產線只是工廠的一部分）、平台、系統、專案

### 產品 (product)

產品是這座工廠的產出。

_避免_：成品、作品、應用

### 廠主 (owner)

廠主是擁有並操作這座工廠的人。

**這座工廠裡只有廠主是人。** 他在關卡上監督工人，但他不執行任何一站。

_避免_：使用者（意思含糊）、客戶、廠長（它與廠主指同一個人）、老闆

### 工人 (worker)

工人是執行一站工作的那一方。**它不是人。**

除了三個關卡以外的每一件事都是工人做的。工人沒有判定權 —— 判定在關卡上，而關卡上站著廠主。

工人每一輪重建，所以它記不住上一輪。它靠 skill 與脈絡知道該做什麼。

_避免_：agent（中文行文寫「工人」）、worker（同上）、機器人、助手、AI

### 終端使用者 (end user)

終端使用者是使用產品的人。他們不碰工廠。

_避免_：使用者（請寫「廠主」或「終端使用者」，兩者差很遠）

### 產品產線 (product line)

產品產線是從一筆需求到產品上線的那條流程。八站：入口、分辨、規格、實作、審查、驗證、上線、監控。

_避免_：產線（單用）、流程、管線、pipeline、工作流

### 站 (station)

站是產品產線上的一道工序。每一站有一份 skill。

_避免_：階段、步驟、節點、環節

### 關卡 (gate)

關卡是一站裡「人說對不對」的那個點。這座工廠有三個：規格、審查、驗證。

_避免_：審查（審查是站名）、檢查點、卡控

### 任務 (task)

任務是一筆進了隊列的工作。底層的一筆任務就是一個 GitHub issue。

_避免_：工單、需求（需求指廠主說的話，還沒成為任務）、issue

### 白話規格 (plain spec)

白話規格用廠主的話描述產品該做到什麼。它在 `SPEC.md`。

_避免_：規格（請指明哪一種）、PRD

### 技術規格 (tech spec)

技術規格描述架構與程式碼的形狀。它在 `docs/tech-spec.md`。

兩種規格分開存，因為變更頻率不同。白話規格很少變，技術規格隨實作反覆調整。混在一起，改架構時會不小心改掉不變量。

_避免_：規格（請指明哪一種）、設計文件

### 不變量 (invariant)

不變量是永遠要成立的產品性質。它寫在白話規格裡，是驗證站的判準來源。

_避免_：規則、約束、條件

### 證據 (evidence)

證據是驗證站的產出：操作錄影、截圖、測試結果。

證據要讓廠主三秒看懂。一份需要閱讀的報告不是證據。

_避免_：報告、結果、產出物

### 風險說明 (risk note)

風險說明是審查站的產出。審查站的產出不是「通過或不通過」，是一份風險說明。

_避免_：審查意見、review comment、報告

### 憑證 (credential)

憑證是任何可以直接存取資料的東西：anon key、access token、service role key、資料庫連線字串。

**前端不持有任何憑證。** HttpOnly 的 session cookie 不算 —— JS 讀不到的東西前端就不算持有。

_避免_：金鑰、密鑰、token

### 防線 (defence layer)

防線是一條規則被放在哪一層。四層強度遞減：架構 > CI／靜態分析 > rules > skill。

_避免_：層級、等級、優先順序

### 預覽 (preview)

預覽是一個 PR 對應的那個可以被操作的產品實例。每個 PR 一個。證據產生器操作的就是它。

_避免_：測試網址、staging、預覽環境

### 初始資料 (seed data)

初始資料是把產品回到已知狀態的那組資料。它存在版本控制裡，而且是合成的 —— 絕不從生產環境複製。

_避免_：假資料、測試資料、fixture

### 測試帳號 (test account)

測試帳號是給工人走的那條固定登入路徑。它只開在預覽專案，生產專案關掉。

_避免_：假帳號、demo 帳號

### 容許清單 (allowance list)

容許清單列出畫面上本來就會變的區域：時間、動畫、隨機排序。逐像素比對證據時跳過這些區域。

_避免_：白名單、忽略清單、例外

### 內迴圈 (inner loop)

內迴圈是一站照它的 skill 做事的那一輪。

_避免_：主迴圈、執行迴圈

### 外迴圈 (outer loop)

外迴圈觀察內迴圈的產出，並以 PR 修改 skill。改 skill 不需要訓練模型。

_避免_：改善迴圈、學習迴圈、訓練

### skill

skill 描述某一站的職責、判準與輸出格式。檔名是 `SKILL.md`。

`fac-` 前綴的是共用的，從腳手架來，不可以改。沒有前綴的是這座工廠自己的。

_避免_：技能檔、prompt、提示詞、指令檔、規則檔

### 修正訊號 (correction signal)

修正訊號是人事後動手改掉的那個東西。它是外迴圈的輸入。

人本來就會修。把修正動作留下來當訊號，是幾乎免費的標註資料。

_避免_：回饋、feedback、標註
