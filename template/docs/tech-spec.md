## 架構規則

這些規則不能改。它們限制架構，不限制技術棧。

1. **前端不持有任何可以直接存取資料的憑證。** 只准 PKCE flow，session 存 HttpOnly cookie。
2. **預覽與生產是不同的專案、不同的帳號。** 不是同一個專案的兩組環境變數。
3. **測試帳號的登入方式只開在預覽專案。**
4. **預覽的位置不可猜測**，並用 service token 擋陌生人。
5. **生產密鑰不進工人的執行層。** 工人只能觸發部署，不能讀密鑰。

第 4 題答「會」時再加三條，見 `.factory/security.md`。

## 部署

部署平台是**起始值**，跟技術棧一樣。它由建廠第 3 站挑，一筆任務換得掉。

腳手架定的不是平台，是預覽機制要滿足的五條：每個 PR 一個預覽、位置猜不到、機器帶 token 進得去、預覽與生產是兩個專案兩個帳號、密鑰由平台注入而工人讀不到。

**換平台之前先對這五條。有一條做不到就停下來。**
